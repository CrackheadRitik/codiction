# Codiction

> **"Get Addicted to Getting Better."**

An AI-Powered Adaptive Coding Interview Preparation Platform.

## Tech Stack

- **Backend:** Django 5.0 + DRF + Channels
- **Frontend:** Next.js 14 + React 18
- **Database:** PostgreSQL (Supabase)
- **Cache:** Redis (Upstash)
- **Judge:** Judge0 CE
- **Hosting:** Render + Vercel

## MVP Features

- User authentication
- Problem repository (500+ problems)
- Online judge (Python)
- Global + Company leaderboards
- Weakness detection
- In-app messaging
- Admin panel

## Quick Start

```bash
cd backend/django_core
source venv/bin/activate
python manage.py runserver
```
